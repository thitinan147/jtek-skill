# jt-card-gate

นี่คือลูปของ repo ที่เปิดอยู่ ไม่ใช่ชุด skill หลายสิบตัว คุณไม่เลือก skill เอเจนต์เรียกขั้นถัดไปผ่าน `/jt-next-step` เอเจนต์ไม่ไปเปิด repo อื่น คุณเปลี่ยนคำบนบรรทัด เอเจนต์ทำเฉพาะข้อที่บรรทัดอนุญาต คนเรียก `/jt-send-back` `/jt-merge` `/jt-drop-card` เอง เอเจนต์ไม่เรียกสามคำสั่งนั้น `/jt-next-step` merge ไม่ได้ กติกานี้เป็นของ skill นี้ ไม่ได้ copy เข้า repo ที่เปิดอยู่

## ติดตั้ง

ครั้งเดียวบนเครื่อง

```bash
npx skills add thitinan147/tek-skill -g
```

## เริ่ม

เปิด git repo ที่จะทำ อยู่บน branch ที่จะเก็บคิว และไม่มีไฟล์ค้างนอกโฟลเดอร์ `card-loop/` แล้วพิมพ์ `/jt-next-step`

คุณไม่เลือก skill เอเจนต์เรียกขั้นถัดไปที่กติกาอนุญาต คุณตอบจนรับร่างเมื่อขั้นนั้นถาม คำสั่งนี้ merge ไม่ได้

## สองเกตก่อน `รอรีวิว`

งานที่แตะโค้ดต้อง review diff ก่อนบรรทัดเป็น `รอรีวิว:` การจดใน plan ไม่นับ ถ้า review นั้นทำไม่ได้ ขั้นคือ `ถาม:` และบรรทัดต้องไม่เป็น `รอรีวิว:` เกตเป็นตัวปฏิเสธ ชนิด `docs` ไม่เปิด ชื่อจาก `<TEK_SKILLS>` ไม่มาทำรีวิวนี้แทน

งานที่ผู้ใช้เห็นจอ ทุกชนิด ไม่เฉพาะ `fix` ต้องสตาร์ท frontend กับ backend จริง แล้วคลิกแอปจริงตามหัว **ตรวจผ่านเมื่อ** ก่อนบรรทัดเป็น `รอรีวิว:` ถ้าคลิกไม่ได้ ขั้นคือ `ถาม:` `<BROWSER_TOOL>` ว่าง ให้เขียน `ถาม:` บรรทัดต้องไม่เป็น `รอรีวิว:` เกตเป็นตัวปฏิเสธ
