# repo-workflow

Skill สำหรับเดินลูป backlog ของ repo หนึ่งตัว คนเขียน card แล้วเปลี่ยนคำบนบรรทัดคิว เอเจนต์อ่านไฟล์นั้น

ติดตั้งเข้า repo ที่จะใช้:

```bash
npx skills add <owner>/repo-workflow
```

ติดตั้งทั้งเครื่องใส่ `-g` เลือกเอเจนต์ใส่ `-a` ตาม [vercel-labs/skills](https://github.com/vercel-labs/skills)

หลังติดตั้ง เปิด repo นั้นแล้วให้เอเจนต์ copy แม่แบบเข้า `work/` และเติมตารางตั้งค่าก่อนหยิบข้อแรก
