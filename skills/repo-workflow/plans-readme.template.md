# Plans

โน้ตลงมือของเอเจนต์ ตาม [`../workflow.md`](../workflow.md) คนไม่รับแผนก่อนเปิด PR

- ไฟล์: `work/plans/<id>.md`
- id ตรงข้อใน [backlog](../backlog/README.md) และชื่อไฟล์ card
- บรรทัด backlog เป็น `ส่งกลับ:` และ `สถานะรอบ` ยังไม่ใช่ `ส่งกลับ` → ตั้ง `รอบหลักฐาน` เป็น 1 แล้วตั้ง `สถานะรอบ` เป็น `ส่งกลับ`
- `สถานะรอบ` เป็น `ส่งกลับ` อยู่แล้ว → ทำต่อ ไม่รีเซ็ตรอบ
- หลักฐานผ่าน → เปลี่ยนบรรทัดเป็น `รอรีวิว:` ตั้ง `สถานะรอบ` เป็น `รอรีวิว` แล้วหยุด
- หัวข้อบังคับอยู่ในไฟล์ plan ที่สร้างจาก `plan.template.md`

เปิดของให้คน review เมื่อหลักฐานใน plan ผ่าน เนื้อมี diff, ผลเทส, และหลักฐานบนพื้นผิวถ้า card ต้องการ สถานะอยู่ที่บรรทัด backlog
