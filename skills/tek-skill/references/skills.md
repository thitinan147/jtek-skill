# Skills สองกลุ่ม

วิธีเดินขั้นอยู่ที่ [loop.md](loop.md)

## ทำให้ tek-skill เก่งขึ้น

ใบกลุ่มนี้สอนวิธีทำงานทั่วไป เช่น สอบคำถามเมื่อ card ยังมีสองทาง หาสาเหตุบั๊กก่อนเขียนเทส หรือตัดของที่ไม่มีคนใช้

`/tek-scan-skills` รายงานชื่อใบกลุ่มนี้ที่ติดตั้งอยู่แล้ว และแนะนำใบจาก skills.sh เมื่อยังไม่มี

`/tek-do-card` ไม่เปิดใบกลุ่มนี้ตอน review โค้ดของ repo ไม่เขียนชื่อกลุ่มนี้ลงแถว `<REPO_SKILLS>`

คนที่อยากใช้ใบกลุ่มนี้เรียกใบนั้นเองนอกคำสั่งของลูป

## ของ repo นี้

ใบกลุ่มนี้พูดถึงภาษา เฟรมเวิร์ก ตัวรันเทส หรือโฮสต์ที่ repo นี้ใช้

`/tek-scan-skills` รายงานใบกลุ่มนี้ที่ติดตั้งอยู่แล้ว และแนะนำใบจาก skills.sh เมื่อ repo ใช้คำนั้นแต่ยังไม่มีใบบนเครื่อง

คนเลือกชื่อแล้วเขียนลงแถว `<REPO_SKILLS>` บน `card-loop/board.md` แถวว่างหรือไม่มีแถวหมายความว่าไม่เปิดใบอื่น

`/tek-do-card` เปิดเฉพาะชื่อในแถวนั้น และเปิดตอน review โค้ดหลัง commit ของ `feat` หรือ `fix` ก่อนตั้ง `รอรีวิว:` ชนิดอื่นไม่เปิด

ชื่อที่ไม่มีในเครื่อง ให้จดใน plan แล้วเดินตาม loop.md ต่อ ห้ามติดตั้งระหว่างทำข้อ ห้ามเปิดใบที่ไม่ได้เขียนในแถว

ตอนหยิบ card ตอนเขียน `ถาม:` และตอนคนเรียก `/tek-open-review` `/tek-send-back` `/tek-mark-merge` `/tek-mark-close` ไม่เปิดใบของ repo

รีวิวของใบเหล่านี้ผ่านแต่หลักฐานใน loop.md ไม่ครบ ห้ามเปิดของให้ review
